
# **GoMadhyaDiaries**

**GoMadhyaDiaries** is a simple yet interactive tourism website that captures the rich culture, heritage, and travel charm of **Madhya Pradesh**, India’s heartland. Designed with a clean UI and engaging visuals, it offers a smooth browsing experience to tourists and travel enthusiasts alike.

---

## **Key Features**

- **Interactive SVG Map of Madhya Pradesh:**  
  The homepage features a custom SVG map with clickable location markers. Hovering over a marker reveals a picture of the respective city, offering a dynamic visual preview.

- **Region-wise Destinations:**  
  Cities and destinations are grouped and presented based on region for easy navigation.

- **Cultural and Culinary Sections:**  
  Highlights of MP’s local food, festivals, art, and heritage.

- **Clean, Responsive Design:**  
  Built using only HTML, CSS, and JavaScript for a lightweight, fast experience.

---

## **Tech Stack**

- **HTML5**  
- **CSS3**  
- **JavaScript (Vanilla)**  
- **SVG** (Scalable Vector Graphics for the map)
